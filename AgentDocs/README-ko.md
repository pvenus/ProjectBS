# AgentDocs

`AgentDocs`에는 Unity가 임포트할 필요가 없는 에이전트 작업 프롬프트, 기획 가이드, 기획 원본 데이터와 참고 자산을 보관한다.

## 폴더 역할

- `workflows/`: 메인 역할의 디렉팅, 완결 핸드오프, 병렬 실행, 임시 작업 생명주기와 보관 등 에이전트 공통 작업 규칙.
- `task-prompts/`: 범위가 정해진 작업을 직접 요청하는 재사용 프롬프트.
- `planning-guides/`: 작성, 평가, 제작 및 데이터 구조 가이드.
- `planning-data/`: ProjectBS 세계관, 스토리, 캐릭터, 전투, 이벤트, 상점 및 아이템 기획 원본.
- `reference-assets/`: 기획 문서에서 참고하는 비런타임 이미지와 맵 원본.

## 이전 출처

- `Assets/Doc`의 파일을 역할별 폴더로 이동했다.
- `Assets/character_concepts`의 파일을 역할별 폴더로 이동했다.
- Unity `.meta` 파일은 의도적으로 제외했다.

문서 간 참조에는 프로젝트 루트 기준 상대 경로를 사용한다. Unity가 런타임 또는 에디터 자산으로 임포트해야 하는 파일만 `Assets` 아래에 둔다.
