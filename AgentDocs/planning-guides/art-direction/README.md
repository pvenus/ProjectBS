# ProjectBS Art Direction Authority

이 폴더는 화감(프로젝트 아트 디렉터)이 소유하는 그래픽 디자인 권위 루트다.
게임 규칙, 일정, 코드 및 Unity 구현을 소유하지 않는다.

## 문서 우선순위

1. `../common/DisignMasterConcept_rule.md` — 문화·시대·최상위 미학
2. `ProjectArtDirection.md` — 프로젝트 공통 시각 언어
3. `DomainImageSpecifications.md` — 용도별 캔버스·표시·구도 규격
4. `ArtReferenceRegistry.md` — 승인 기준과 반례의 정확한 파일
5. `ArtProductionApprovalWorkflow.md` — 생성 전 명세와 검수·승인 게이트
6. 도메인별 현행 가이드 — 의미·저장·도메인 특수 조건

충돌 시 위 순서를 따른다. 레거시 PixelLab 가이드와 과거 프롬프트는 감사 증거일 뿐 신규 시각 기준이 아니다.
`Assets/ImagesGenerated`에 존재한다는 사실만으로 승인되지는 않는다.

## 현황 문서

- `CurrentGraphicsAudit_2026-08-27.md`: 2026-08-27 층화 표본 감사와 개선 백로그

## 소유 경계

- 화감: 시각 방향, 이미지 명세, 기준 이미지, 검수와 승인
- 벼리: 게임 의도·규칙·서사 사실
- 이음: 우선순위·일정·출시 범위
- 한결: 임포트·렌더링·메모리·자동 검사와 코드
- 가온: 경계 충돌 조율
