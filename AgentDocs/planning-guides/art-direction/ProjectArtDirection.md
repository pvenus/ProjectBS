## 1. 한 문장 방향

ProjectBS는 **조선시대의 생활감과 설화적 긴장을, 닥종이 바탕 위의 절제된 먹선·담채·민화적 평면성으로 읽히게 만드는 2D 게임**이다.

전통 소재를 장식처럼 덧붙이지 않는다. 복식·건축·무기·생활 도구의 시대성이 실루엣과 화면 구조에서 먼저 드러나야 한다.

## 2. 고정 시각 문법

### 선과 형태

- 바깥 실루엣은 내부 묘사보다 분명하다.
- 먹선은 손맛과 굵기 변화가 있으나 형상을 흐리게 만들 정도로 번지지 않는다.
- 인물과 아이콘은 축소 시에도 한 개의 주 실루엣이 먼저 읽힌다.
- 형태는 평면적으로 정리하고 물리 기반 3D 볼륨, 렌즈광, 금속 광택을 기본 문법으로 삼지 않는다.

### 색과 명암

- 기본 바탕은 미색·먹색·회갈색·흙색의 낮은 채도다.
- 핵심 식별색은 한 자산당 1~2개 계열로 제한한다. 전통 청·적·황·백·흑의 관계 안에서 사용한다.
- 검정이 넓은 면을 삼켜 실루엣 내부가 사라지지 않게 한다.
- 네온 보라·전기 청록·과도한 발광은 초자연 의미가 명확한 경우에도 작은 강조로만 허용하며, 화면 전체 팔레트가 되면 반려한다.

### 질감과 재질

- 종이결, 먹 번짐, 마른 붓, 담채 얼룩을 제한적으로 사용한다.
- 모든 면에 동일한 디지털 필터를 덮지 않는다. 질감은 형태와 재질을 설명해야 한다.
- 금속·목재·천·종이는 색과 가장자리, 제한된 명암으로 구분한다. 사진식 하이라이트와 3D 재질 렌더는 금지한다.

### 공간과 구도

- 전통 회화의 여백을 기능적 공간으로 사용한다.
- 배경은 플레이 오브젝트가 놓일 중앙·전경의 대비와 여백을 보존한다.
- 팝업 이미지는 핵심 순간 1개, 핵심 행동 1개, 주 시선 대상 1개를 원칙으로 한다.
- UI 이미지는 장식보다 상태·상호작용·정보 위계를 먼저 읽히게 한다.

## 3. 도메인 간 통일과 차이

모든 도메인은 먹선, 종이성, 절제된 전통색, 평면적 형태를 공유한다. 표현 밀도만 용도에 맞게 달라진다.

| 도메인 | 허용 밀도 | 우선 읽힘 |
| --- | --- | --- |
| 캐릭터 | 중간 | 전신 실루엣, 얼굴 방향, 복식·무기 |
| 스킬·아이템 아이콘 | 낮음 | 단일 상징, 방향, 효과 계열 |
| 캐릭터/스킬 애니메이션 | 낮음~중간 | 자세 변화, 타격 방향, 프레임 중심 |
| 스토리 팝업 | 높음 | 사건의 한 순간과 인물 관계 |
| 전투 배경 | 중간 | 전투 여백, 깊이층, 장소 정체성 |
| UI 프레임·패널 | 낮음 | 기능 상태, 테두리, 텍스트 안전 영역 |

## 4. 허용 가능한 변주

- 밤·비·안개·원혼 장면에 한해 명도와 차가운 보조색 변화
- 인물의 계층·직업·성격을 위한 선 굵기와 의복 채도의 제한적 차이
- 민화적 장식, 수묵 선화, 담채 삽화 사이의 밀도 변화
- 아이콘의 공격 방향에 따른 방사형·대각선·중앙형 구도 변화

변주 후에도 동일 화면의 형제 자산과 비교했을 때 선의 계층, 종이성, 색역, 시각적 무게가 같은 가족으로 읽혀야 한다.

## 5. 허용 불가 이탈

- 실사 인물, 영화 스틸, 3D 렌더, 서구 판타지 카드 일러스트
- 네온 보라·청록 발광과 검은 안개가 화면을 지배하는 모바일 판타지 VFX
- 중국·일본·서구의 복식, 갑주, 건축, 문양을 한국 전통의 대체물로 사용
- 모든 표면을 세밀하게 묘사해 80~200px UI에서 뭉개지는 구성
- 아이콘마다 불투명 배경·투명 배경, 원근·질감·색역이 임의로 바뀌는 상태
- 동일 캐릭터의 얼굴 비례, 나이, 체형, 핵심 복식색과 장비가 프레임마다 바뀌는 상태
- 생성기 특유의 가짜 글자, 워터마크, 기형 손·무기, 절단된 실루엣

## 6. 고정 규칙과 콘텐츠별 정보 분리

모든 새 이미지 요청은 다음을 분리한다.

**고정 규칙:** 본 문서, 도메인 규격, 기준 이미지 ID, 선·색·질감·배경·금지 규칙, 표시 크기 시험.  
**변동 정보:** 콘텐츠 ID, 인물·사건·스킬 의미, 포즈·행동·소품, 고유 강조색과 출력 파일명.

고정 규칙은 개별 프롬프트가 재해석하거나 축약해 변경할 수 없다. 변경하려면 화감 승인, 레지스트리 버전 증가, 영향 도메인 재검수가 필요하다.
