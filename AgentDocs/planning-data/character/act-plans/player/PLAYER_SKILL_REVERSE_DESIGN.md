# 플레이어 캐릭터 스킬 역기획 보강

## 문서 성격

이 문서는 메인 플레이어 캐릭터의 현재 스킬 JSON과 확정된 스킬 애니메이션을 기준으로 복원한 설명 문서다. 수치 밸런스와 런타임 데이터의 권위 원천은 `Assets/Contents/Skill/json`이며, 이 문서는 캐릭터 역할·스킬 의미·아이콘 제작 방향을 보강한다.

아이콘 생성용 상세 묘사와 현재 4프레임 루프를 재현하기 위한 프레임별 애니메이션 역기획은 `AgentDocs/planning-data/character/act-plans/player/PLAYER_SKILL_MEDIA_REVERSE_DESIGN.md`를 따른다.

등급별 공통 규칙은 다음과 같다.

- 기본 공격, 패시브, Active 1은 1~3등급에서 공유한다.
- Active 2는 2~3등급에서 사용한다.
- Active 3은 3등급에서만 사용한다.
- 등급 변형은 같은 스킬 정체성을 유지하면서 색의 밀도, 먹선의 힘, 보조 입자와 강조 범위로 강도를 구분한다.
- 아이콘 파일의 정식 ID는 해당 스킬의 `equipmentId + ".icon"`이다.
- 아이콘은 전투 중 작은 크기에서도 다른 스킬과 즉시 구분되는 단일 핵심 오브젝트 또는 단일 동작을 사용한다.

## 서진 — 전열 지휘관

서진의 스킬은 환도, 돌파, 진형, 거북선 화력으로 확장되는 전열 지휘관의 성장선이다. 푸른 먹색과 회갈색을 기본으로 하고, 상위 등급에서는 황동색 또는 화포의 주홍빛을 제한적으로 더한다.

### 기본 공격 — 전열베기

- ID 패턴: `skill.character.seojin.{grade}.basic_attack.basic_attack`
- 묘사: 환도를 짧고 무겁게 휘둘러 전방의 적을 베는 근접 기본 공격이다. 화려한 검기보다 전열을 밀어내지 않고 유지하는 안정적인 일격으로 읽혀야 한다.
- 아이콘 모티프: 화면을 가르는 한 번의 굵은 환도 먹선과 짧은 청회색 절단 흔적. 검 전체보다 날의 방향과 한 번의 베기 궤적을 우선한다.

### 패시브 — 불퇴전

- ID 패턴: `skill.character.seojin.{grade}.passive_1.indomitable`
- 묘사: 피해와 압박을 받아도 전열을 이탈하지 않는 서진의 버팀과 결의를 나타낸다. 공격 스킬처럼 보이기보다 방어 의지와 흔들리지 않는 중심을 표현한다.
- 아이콘 모티프: 땅에 단단히 박힌 환도 또는 방패형 먹선 뒤에 남는 한 줄의 푸른 기세. 성벽, 서양 문장, 과도한 갑옷 도상은 사용하지 않는다.

### Active 1 — 돌격

- ID 패턴: `skill.character.seojin.{grade}.active_1.*`
- 묘사: 목표 방향으로 단숨에 파고들어 전열을 깨고 충돌 지점에 강한 베기 충격을 남긴다. 준비 동작보다 전진 방향과 충돌의 힘이 핵심이다.
- 아이콘 모티프: 우상향 또는 우측으로 뻗는 하나의 돌진 붓선, 환도 끝의 압축된 충격점. 등급이 높을수록 보조 먹 파편과 산화 주홍 강조를 늘린다.

### Active 2 — 학익진

- ID 패턴: `skill.character.seojin.{grade}.active_2.crane_wing_formation`
- 사용 등급: 2~3등급
- 묘사: 학의 양 날개처럼 좌우로 펼쳐지는 지휘선으로 적의 움직임을 억제하고 아군의 전열 공간을 만든다. 단순 회전 효과가 아니라 중앙 지휘점에서 양쪽으로 벌어지는 진형 변화가 보여야 한다.
- 아이콘 모티프: 중앙의 작은 지휘 매듭과 좌우로 펼쳐진 두 개의 학익형 먹선. 새 한 마리의 사실적 그림보다 진형의 V자 또는 열린 날개 구조를 우선한다.

### Active 3 — 거북선 돌격

- ID: `skill.character.seojin.3.active_3.turtle_ship_assault`
- 사용 등급: 3등급
- 묘사: 측면에서 돌진하는 거북선의 중량감과 화포 지원을 함께 호출하는 복합 스킬이다. 거북선 본체의 이동과 별도의 화포 지대 효과가 서로 다른 역할로 읽혀야 한다.
- 아이콘 모티프: 오른쪽을 향한 거북선 측면 실루엣과 선수 또는 포구의 작은 주홍 화염 한 점. 정면 원근이나 여러 척의 함대는 피한다.

### 보조 스킬 — 화포 지대

- ID: `skill.character.seojin.3.turtle_ship_cannon_zone`
- 묘사: 포탄이 떨어진 지점을 중심으로 지면의 화염과 충격파가 반복되는 지역 효과다. 거북선 소환과 구분되도록 배보다 지면 파동과 잔류 화력을 강조한다.
- 아이콘 모티프: 갈라진 지면 중심의 둥근 화포 충격과 낮게 번지는 주홍·먹색 파동. 완전한 거북선을 다시 넣지 않는다.

## 유진 — 추적 궁수와 의적 지휘자

유진의 스킬은 한 발의 정확한 화살에서 다중 투사체 운용, 관통 사격, 의적 동료 소환으로 확장된다. 화살 스킬은 실제 투사체가 여러 개 생성될 수 있으므로 아이콘과 애니메이션 모두 화살 한 발을 핵심 단위로 삼는다.

### 기본 공격 — 추적 화살

- ID 패턴: `skill.character.yujin.{grade}.basic_attack.basic_attack`
- 묘사: 목표를 향해 곧게 날아가는 한 발의 원거리 기본 공격이다. 넓은 폭발보다 방향성과 정확도가 우선한다.
- 아이콘 모티프: 가늘고 긴 단일 화살과 짧은 바람 꼬리. 여러 화살 다발이나 활 전체를 동시에 넣지 않는다.

### 패시브 — 흔적 읽기

- ID 패턴: `skill.character.yujin.{grade}.passive_1.passive_1`
- 묘사: 주변의 움직임과 흔적을 빠르게 읽어 유진의 사격 흐름을 안정시키는 추적자 감각이다. 직접 피해보다 관찰, 조준, 다음 사격 준비의 의미가 중심이다.
- 아이콘 모티프: 희미한 발자국 또는 바람결 위에 겹친 작은 화살촉 표식. 서양식 조준경이나 기계식 크로스헤어는 사용하지 않는다.

### Active 1 — 멀티샷

- ID 패턴: `skill.character.yujin.{grade}.active_1.multi_shot`
- 묘사: 얇고 긴 화살 한 발을 빠르게 발사하며, 런타임에서 동일 투사체를 여러 방향 또는 여러 개로 전개하는 스킬이다. 한 이미지 안에 화살 묶음을 그리는 방식보다 복제 가능한 단일 화살의 속도감을 유지한다.
- 아이콘 모티프: 하나의 가는 화살과 둘 또는 셋으로 갈라지는 짧은 잔상. 주 오브젝트는 끝까지 한 발로 읽혀야 한다.

### Active 2 — 활빈 연사·관통 사격

- ID 패턴: `skill.character.yujin.{grade}.active_2.hwalbin_barrage`
- 사용 등급: 2~3등급
- 묘사: 의적 궁수의 힘을 한 발에 모아 적의 대열을 꿰뚫는 고속 관통 사격이다. 멀티샷과 달리 분산보다 직선 관통력, 압축된 바람, 길게 이어지는 먹선이 핵심이다.
- 아이콘 모티프: 길고 날카로운 단일 화살촉과 뒤로 밀려나는 동심형 바람 또는 찢긴 종이 결. 등급이 높을수록 화살촉 주변의 산화 적색 또는 청백색 강조를 늘린다.

### Active 3 — 의적 출현

- ID: `skill.character.yujin.3.active_3.outlaw_appearance`
- 사용 등급: 3등급
- 묘사: 연기와 먹바람 속에서 유진의 의적 동료들이 나타나 일정 시간 함께 싸우는 소환 스킬이다. 연출은 소환 연기, 캐릭터 등장, 제한 시간 후 해제의 순서로 이해한다.
- 아이콘 모티프: 갈라지는 검은 연기 속에서 드러나는 삿갓 또는 매듭 표식 하나. 여러 인물의 작은 전신을 나열하지 않는다.
- 클론 규칙: `character.yujin.3.clone`은 별도 스킬셋을 가진 소환체지만 Active 3은 보유하지 않는다. 기본 공격·패시브·Active 1·Active 2는 소환체용 ID를 사용한다.

## 지한 — 약술과 기혈을 다루는 지원가

지한의 스킬은 기파로 적을 견제하고, 약재와 탕약으로 아군을 유지하며, 최고 등급에서 침술로 전황을 되돌리는 지원가의 성장선이다. 먹갈색, 약초 녹색, 따뜻한 황토색을 기본으로 하고 신성 효과에만 옅은 청백색을 제한적으로 사용한다.

### 기본 공격 — 기파술

- ID 패턴: `skill.character.jihan.{grade}.basic_attack.basic_attack`
- 묘사: 지팡이나 손끝에서 압축한 기를 짧은 파동으로 내보내는 기본 공격이다. 물리 타격보다 둥글게 밀려나는 기의 압력과 절제된 수행자의 동작으로 읽혀야 한다.
- 아이콘 모티프: 염주 한 알 또는 지팡이 끝에서 퍼지는 한 겹의 원형 기파. 거대한 폭발이나 번개로 보이지 않게 한다.

### 패시브 — 기혈 순환

- ID 패턴: `skill.character.jihan.{grade}.passive_1.blood_qi_circulation`
- 묘사: 호흡과 기혈의 흐름을 고르게 유지해 지한과 아군의 생존 흐름을 보조한다. 피를 직접 묘사하기보다 몸 안을 순환하는 따뜻한 기운과 안정된 호흡을 나타낸다.
- 아이콘 모티프: 닫히지 않은 원을 따라 도는 두 개의 부드러운 먹·황토 붓선과 중앙의 작은 숨결 점.

### Active 1 — 탕약 처방

- ID 패턴: `skill.character.jihan.{grade}.active_1.medicine_prescription`
- 묘사: 약재를 배합해 즉시 사용할 수 있는 탕약의 기운을 펼치는 지원 스킬이다. 온전한 그릇이 여러 프레임 반복되는 표현보다 약재, 끓는 기운, 완성된 처방이 순환하는 의미를 사용한다.
- 아이콘 모티프: 작은 약사발 하나와 위로 오르는 약초색 증기 한 줄. 사발은 한 번만 온전하게 보이고 주변에는 약잎 또는 처방 종이 한 조각만 둔다.

### Active 2 — 십전대보탕

- ID 패턴: `skill.character.jihan.{grade}.active_2.ten_tonic_soup`
- 사용 등급: 2~3등급
- 묘사: 여러 약재의 보양 기운을 한데 모아 지속적인 회복과 강화의 영역을 만드는 상위 탕약술이다. Active 1의 단일 처방과 달리 여러 약재의 조화와 넓게 순환하는 온기를 강조한다.
- 아이콘 모티프: 중심의 약탕 기운을 둘러싼 서로 다른 세 개의 약잎·뿌리 표식과 황토색 순환 붓선. 동일한 그릇을 반복해서 그리지 않는다.

### Active 3 — 신의 침술

- ID: `skill.character.jihan.3.active_3.divine_acupuncture`
- 사용 등급: 3등급
- 묘사: 정확한 혈자리에 침을 놓아 위급한 아군의 기혈을 강하게 되돌리는 최고 등급 지원술이다. 단순한 회복 파동보다 한 점에 집중된 침, 이어지는 경락선, 순간적으로 살아나는 기운이 핵심이다.
- 아이콘 모티프: 가는 침 한 개가 빛나는 혈자리 한 점을 짚고, 그 지점에서 두 갈래의 청백·황토 경락선이 퍼지는 구성. 주사기나 현대 의료 기구처럼 보이지 않게 한다.

## 아이콘 제작 공통 판독 규칙

- 1:1 정사각형, 투명 배경, UI 축소 후에도 중심 실루엣이 남아야 한다.
- 글자, 숫자, 등급 표기, 테두리 프레임, 카드 배경을 이미지에 포함하지 않는다.
- 한 아이콘에는 핵심 오브젝트 하나와 보조 궤적 최대 두 종류만 둔다.
- 메인 질감은 거친 가변압 먹선이며, 수채·파스텔 입자는 보조 운동감으로만 사용한다.
- 같은 캐릭터 안에서도 기본 공격, 패시브, 각 Active가 오브젝트 실루엣만으로 구분되어야 한다.
- 완전한 동일 오브젝트를 여러 번 반복 배치하지 않는다. 다중 발사나 반복 적용은 잔상, 분기선, 파동으로 표현한다.
- 실제 파일명은 `Assets/ImagesGenerated/Skill/icon/{equipmentId}.icon.png`만 허용하며 레거시 ID 또는 Resources 경로를 사용하지 않는다.
