================================================================================
FaithDetail UI/UX 탭 & 트랙 기반 개편 및 UITabWidget 세팅 가이드 (최신판)
================================================================================

본 문서는 신앙 상세(Faith Detail) UI/UX를 기존 4컬럼 나열형에서 '탭 기반 단일 신앙 집중 및 10칸 Progress Bar 진행 트랙' 구조로 전면 재구성하고, 동적 탭 생성 및 페이지 전환을 지원하는 재사용 가능한 [UITabWidget]을 적용하여 처음부터 동일한 환경을 셋업할 수 있도록 돕는 완전한 최신 연동 가이드입니다.

--------------------------------------------------------------------------------

--------------------------------------------------------------------------------

2. UITabWidget 위젯 개요 및 자동 구성 방법
--------------------------------------------------------------------------------
[UITabWidget]은 여러 개의 탭 버튼을 자동 생성하고 정렬(가로/세로)해주며, 각 버튼에 매핑된 GameObject 페이지를 자동으로 토글(On/Off)해주는 범용 재사용 가능 위젯입니다.

* 인스펙터 주요 설정 필드:
  - Tab Alignment: Horizontal(가로) 또는 Vertical(세로) 중 선택합니다.
  - Tab Button Prefab: 탭 버튼으로 복사 생성할 버튼 프리팹을 할당합니다. (자식에 Text 혹은 TMP_Text 포함 필수)
  - Spacing: 버튼 사이의 여백 간격 수치를 조절합니다.
  - Normal Color / Selected Color: 탭 버튼들의 기본 상태 및 선택 상태의 색상을 정의합니다.
  - Pages Setup: 탭으로 제어할 페이지 목록을 채웁니다.
    * Tab Name: 버튼에 들어갈 탭의 이름 (예: "생명", "전쟁")
    * Page Object: 해당 탭 버튼을 눌렀을 때 활성화될 페이지 GameObject를 연결합니다.

* 자동 생성 실행:
  - 컴포넌트 우측 상단 옵션 메뉴(...)에서 [Rebuild Tab Widget]을 클릭합니다.
  - 위젯이 자동으로 'TabButtonsRoot' 오브젝트를 만들고, LayoutGroup(Horizontal 또는 Vertical) 및 ContentSizeFitter 컴포넌트를 붙여 정렬 설정을 맞춘 뒤, Pages Setup에 정의된 수에 맞게 버튼 프리팹들을 인스턴스화하여 자식으로 채워 넣습니다.
  - 또한 각 버튼의 텍스트를 설정된 Tab Name으로 자동 변경합니다.

--------------------------------------------------------------------------------
3. 씬(Scene) 배치 방법
--------------------------------------------------------------------------------
1) Unity Editor에서 'Assets/_machal/Scenes/UITestScene.unity' 씬을 엽니다.
2) Canvas 하위에 'UI_FaithDetail.prefab'을 끌어다 놓아 프리팹 인스턴스를 만듭니다.
3) 해당 UI_FaithDetail 오브젝트가 활성화(Active) 상태에서 정상적으로 화면 전체를 덮도록 RectTransform의 Anchor를 Stretch-Stretch로 맞추어 줍니다.

4. Inspector 연결 및 설정 (FaithDetailView)
--------------------------------------------------------------------------------
'UI_FaithDetail' 오브젝트에 부착된 [FaithDetailView] 컴포넌트의 인스펙터 항목들을 아래와 같이 연결합니다.

[Tabs]
* tabWidget:
  - 'UI_TabButtons' 오브젝트(UITabWidget 컴포넌트가 부착된 오브젝트)를 드래그하여 연결합니다.
  - (팁: 만약 이 필드가 비어있더라도 플레이 시작 시 자식 오브젝트에서 자동으로 UITabWidget을 찾아 바인딩하는 스마트 Fallback이 적용되어 있습니다.)
* tabButtons, tabTexts (레거시 백업용):
  - 이제 더 이상 수동으로 탭 버튼들을 하나씩 드래그 앤 드롭하지 않아도 됩니다. (비워두셔도 정상 동작합니다.)

[Track (ProgressBar)]
* trackProgressBar:
  - 10칸 눈금이 시각적으로 디자인된 UI Slider 컴포넌트를 드래그하여 연결합니다.
  - Slider의 Min Value = 0, Max Value = 1로 설정합니다.
* trackNodes (Size: 10):
  - 진행 트랙 가로 배열 상에 배치된 10개의 레벨 노드 오브젝트를 1레벨부터 10레벨 순서로 드래그하여 연결합니다.
  - 각 노드에는 [FaithNodeView] 컴포넌트가 부착되어 있어야 합니다.
* currentLevelText:
  - 현재 선택된 신앙의 레벨(예: "Lv. 4")을 표시할 TMP_Text 컴포넌트를 연결합니다.
* faithNameText:
  - 현재 선택된 신앙의 이름(예: "생명의 신")을 표시할 TMP_Text 컴포넌트를 연결합니다.

[Effect Cards]
* currentEffectsRoot:
  - '현재 적용 중인 효과' 아이템들이 동적으로 스폰되어 스택 형태로 쌓일 부모 Layout 오브젝트(Vertical Layout Group 및 Content Size Fitter 부착 권장)를 연결합니다.
* nextEffectsRoot:
  - '다음 레벨 해금 예정 효과' 아이템들이 동적으로 스폰될 부모 Layout 오브젝트를 연결합니다.
* effectItemPrefab:
  - 템플릿으로 사용할 UI_FaithEffectItem 프리팹(혹은 비활성화해 둔 씬 내 템플릿 오브젝트)을 드래그하여 연결합니다.

[Desc Panel Bindings]
* panelDesc:
  - 하단 상세 설명 영역의 부모 패널(RectTransform)을 연결합니다.
* descTitleText:
  - 설명 패널 내의 제목 텍스트 컴포넌트(TMP_Text)를 연결합니다.
* descContentText:
  - 설명 패널 내의 본문 상세 설명 텍스트 컴포넌트(TMP_Text)를 연결합니다.

5. TestFaithManager 연결 방법
--------------------------------------------------------------------------------
1) 씬 안의 'TestFaithManager' 오브젝트를 선택합니다.
2) [TestFaithManager] 컴포넌트의 인스펙터에서 아래 필드들을 확인하고 할당합니다.
   * Views:
     - faithDetailView: 위에서 세팅한 씬 내의 UI_FaithDetail 오브젝트를 연결합니다.
   * Mock Configurations:
     - defaultLockedSilhouetteIcon: 미해금 노드나 잠금 상태 노드에 표시할 기본 자물쇠/실루엣 아이콘 스프라이트를 설정합니다.
     - blessingUpgradeIcon: 2, 4, 6, 7, 9, 8레벨 등의 축복 강화 표기용 화살표 또는 강화 스프라이트를 설정합니다.
     - classEvolutionIcon: 5, 10레벨 등의 전직/진화 보상을 나타낼 전직 전용 스프라이트를 설정합니다.
     - questionMarkIcon: 5레벨 확정 신앙 노드 등에 사용될 물음표(신비로운) 스프라이트를 설정합니다.

6. 수동 UI 설정 및 연출 최적화 팁 (Fitter & Layouts)
--------------------------------------------------------------------------------
* 동적 크기 조절:
  - currentEffectsRoot와 nextEffectsRoot 트랜스폼에는 반드시 Vertical Layout Group과 Content Size Fitter를 함께 세팅하십시오.
  - Content Size Fitter의 Vertical Fit 속성을 'Preferred Size'로 주면 효과 개수(최소 1개에서 유물/전직 추가 시 3개 이상)에 맞추어 카드 패널 높이가 자연스럽게 조절됩니다.
* 노드 터치 반응:
  - 10개의 trackNodes 슬롯은 Raycast Target이 켜져 있어야 클릭을 정상 감지합니다.
  - 마우스 오버(Tooltip) 연동 시 UI 프레임워크의 이벤트 시스템을 통해 FaithNodeView의 클릭 이벤트가 HandleNodeClicked로 무리 없이 흐르는지 확인해 주세요.
